# Getting Started with the Vue Toast Component

A quick start project demonstrating how to create and configure the Syncfusion Vue Toast component in a Vue application with various positions, timeout settings, and HTML template rendering capabilities.

## Overview

This project provides a comprehensive introduction to the Syncfusion Vue Toast component. It includes practical examples showing how to implement toast notifications with different positions, configure timeout durations, and render custom HTML templates within toast messages. This is an ideal starting point for developers looking to integrate toast notifications into their Vue applications.

## Features

- Multiple toast position options (top, bottom, left, right)
- Configurable timeout durations for notifications
- HTML template support for custom content rendering
- Easy integration with Vue projects
- Responsive and lightweight implementation
- Automatic reload on source file changes during development

## Prerequisites

Before starting this project, ensure you have the following installed on your machine:

- NodeJS (latest stable version)
- Vue (latest version compatible with the project)
- Visual Studio Code (latest version)
- Basic understanding of Vue.js fundamentals

## Installation

1. Clone the `getting-started-with-the-vue-toast-component` repository
2. Navigate to the project directory
3. Install the necessary packages by running:
   ```
   npm install
   ```
   This command will install all the required Vue packages and dependencies needed to run the application locally.

## How to Run This Application

1. Open the cloned repository in Visual Studio Code
2. To start the development server, run:
   ```
   npm run dev
   ```
3. Navigate to `http://localhost:5174/` in your web browser
4. The application will automatically reload whenever you modify any source files

## Configuration Options

You can customize toast notifications by adjusting:

- Toast position and alignment
- Display duration (timeout values)
- Custom HTML templates for message content
- Toast styling and animations
- Action buttons and callbacks
